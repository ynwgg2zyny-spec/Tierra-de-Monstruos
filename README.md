# Tierra de Monstruos

Juego de supervivencia en 3D low-poly para el navegador (móvil, tablet y ordenador).

**Jugar:** https://ynwgg2zyny-spec.github.io/Tierra-de-Monstruos/

Capítulo 1: la Jungla. Recolecta, fabrica, monta tu campamento nómada y derrota al Gorila gigante.

Para jugar en local: `node server.mjs` y abrir http://localhost:8642
